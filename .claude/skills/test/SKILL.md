# test

변경된 파일을 감지해 연관 테스트를 선별 실행한다. 실패 시 원인을 분석하고 수정 방향을 제안한다.

## 참조 파일

- `references/file-test-map.md` — 소스 파일 → 테스트 파일 매핑 규칙

## 실행 순서

1. 변경된 Python 파일을 감지한다
   ```bash
   git diff --name-only HEAD
   git diff --name-only --cached
   ```
   - 변경 파일이 없으면 전체 테스트를 실행한다

2. `references/file-test-map.md`의 매핑 규칙으로 연관 테스트 파일을 결정한다
   - 매핑되는 테스트 파일이 없으면 전체 테스트를 실행한다

3. pytest를 실행한다
   ```bash
   # 선별 실행
   python -m pytest {테스트파일1} {테스트파일2} -v

   # 전체 실행
   python -m pytest
   ```

4. 결과를 파악한다
   - **전체 통과**: 결과 보고 후 종료
   - **실패 있음**: 5단계로 진행

5. 실패한 테스트에 대해 원인을 분석한다
   - 에러 메시지와 스택 트레이스를 읽는다
   - 관련 소스 파일을 읽어 근본 원인을 파악한다
   - 수정 방향을 구체적으로 제안한다 (파일명:라인 수준)

6. 결과를 보고한다

## 결과 보고 형식

**통과 시:**
```
테스트 통과 ✓
실행: {N}개 | 통과: {N}개 | 스킵: {N}개
```

**실패 시:**
```
테스트 실패
실행: {N}개 | 통과: {N}개 | 실패: {N}개

실패 원인:
- {테스트명}: {에러 요약}
  → 수정 제안: {파일명}:{라인} — {수정 방향}
```
